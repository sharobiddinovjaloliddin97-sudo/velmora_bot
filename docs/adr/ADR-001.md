# ADR-001: Custom User Model

## Status
Accepted

## Decision
The project uses a custom Django `User` model extending `AbstractUser`. Authentication is based on the `email` field instead of `username`.

## Reason
- Email is unique and better suited for authentication.
- Allows future extension with project-specific user fields.
- Avoids replacing the default user model later in the project.

## Consequences
- `AUTH_USER_MODEL` is set to `users.User`.
- All future relationships must reference `settings.AUTH_USER_MODEL`.
- Authentication uses email as the login identifier.
