## Implementation
- Authentication credentials are validated using Django's `authenticate()` API.
- JWT tokens are generated through `RefreshToken.for_user(user)` from SimpleJWT.
- Login logic is encapsulated in a dedicated `LoginSerializer`.

- Login requests are handled by a dedicated `LoginView` based on `GenericAPIView`.
- Authentication logic is delegated to `LoginSerializer`, while the view is responsible for constructing the HTTP response.
